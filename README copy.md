# Manish Kumar — Portfolio

A responsive, static portfolio site built with plain HTML, CSS, and JavaScript. It has no build step or package dependencies and can be deployed directly to GitHub Pages.

## Run locally

Open `index.html` in a browser. The résumé download is served from `Manish_kumar_AI_Engineer.pdf` in the repository root.

## Deploy to GitHub Pages

1. Create a GitHub repository named `your-username.github.io` for a user site, or use any repository name for a project site.
2. Push the contents of this folder to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish. The site will be available at `https://your-username.github.io/` for a user site, or `https://your-username.github.io/repository-name/` for a project site.

Keep `index.html`, `styles.css`, `script.js`, and the résumé PDF together in the repository root. Update the résumé PDF link in `index.html` if its filename changes.
